# BankFlow – Core Banking & Payment Integration API

🚧 **In Development**

A secure banking backend built with ASP.NET Core, simulating core banking
operations and payment-system integration.

## Tech Stack
- C#, ASP.NET Core Web API (.NET 8)
- SQL Server, T-SQL stored procedures, Entity Framework Core
- JWT authentication, role-based access control
- xUnit, Docker, GitHub Actions (CI/CD), Swagger

## Planned Features
- Customer accounts, deposits, withdrawals and fund transfers (REST API)
- Mock CEFT/SLIPS-style interbank transfer integration
- AML rule checks to flag large or unusual transactions
- Audit logging and OWASP-based secure coding practices
- Unit tests and automated CI pipeline
